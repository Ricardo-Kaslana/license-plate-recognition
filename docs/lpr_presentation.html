项目概述
Project Overview

基于深度学习的中国车牌端到端识别系统，采用两阶段流水线架构。

Stage 1

车牌检测与定位

YOLOv8-Pose 检测车牌区域并输出4个角点关键点，实现精确定位与透视矫正。

YOLOv8n-Pose Corner Detection CCPD2019

CNN 视觉编码器 + Transformer 解码器，自回归生成车牌字符序列。

CNN 编码器细节

4 层 BasicBlock（ResNet 风格残差块）
16× 空间下采样 (48×160 → 3×10)
输出 512 维特征向量
特征图展平为 30 个序列 token

Transformer 解码器细节

d_model = 512, nhead = 8
6 层 Transformer Decoder
正弦位置编码 (Positional Encoding)
自回归生成，</s> 终止符停止

模型细节
Model Details
Detection

YOLOv8-Pose 检测模型

基座模型：yolov8n-pose.pt
训练数据：CCPD2019 车牌数据集
输出：BBox + 4 个角点关键点
角点顺序：TL → TR → BR → BL
训练参数：100 epochs, batch=16, imgsz=640

Recognition

CNN-Transformer 识别模型

输入：矫正车牌 48×160
CNN：4× BasicBlock, 16× 下采样
特征尺寸：3×10 空间 → 30 tokens
Transformer：6层 decoder, 8头注意力
输出：自回归字符序列 ≤ 8 字符

数据流处理
Data Pipeline & CCPD Format

CCPD2019 文件名编码了车牌的全部标注信息

▼ CCPD 文件名示例
025-95_113-154&383_386&473-386&473_177&454_154&383_363&402-0_0_22_27_27_33_16-37-15.jpg
面积 | 倾斜度 | BBox: xmin&ymin_xmax&ymax | 4角点: BR_BL_TL_TR | 字符索引序列 | 亮度 | 模糊度

CCPD 原始格式

[右下, 左下, 左上, 右上]
BR → BL → TL → TR
索引: [0, 1, 2, 3]

数据集/LPR 格式

[左上, 右上, 右下, 左下]
TL → TR → BR → BL
索引映射: [2, 3, 0, 1]

角点用于计算 透视变换矩阵，将倾斜/旋转的车牌矫正为正向的 48×160 图像，再送入识别模型。 透视矫正确保字符区域对齐，大幅提升识别准确率。

总结与展望
Summary & Future Work
两阶段架构优势

检测与识别解耦，各阶段可独立优化和升级。透视矫正弥补了倾斜/旋转带来的识别困难。

CNN + Transformer 融合

CNN 提取局部视觉特征，Transformer 建模序列全局依赖，结合了两者优势。

端到端可部署

提供命令行推理 + Web 应用两种交互方式，满足开发调试与产品化需求。

未来方向

支持更多车牌类型（新能源/双层）、端侧部署（ONNX/TensorRT）、视频实时流处理、多车牌同时检测。
